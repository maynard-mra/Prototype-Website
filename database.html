What is a data breach?

Understanding the Database

A data breach occurs when unauthorised individuals gain access to confidential information typically through hacking, phishing, or poor security practices. Our database catalogues publicly known breaches, documenting which organisations were affected, how many accounts were compromised, and what types of data were exposed.

What data do we track?

We record the breach name, affected domain, date of incident, number of accounts compromised, and the types of data that were leaked (e.g. passwords, emails, phone numbers).

How to use this database

Use the search bar above to filter breaches by name or data type. If a service you use appears here, we strongly recommend changing your password immediately and enabling two-factor authentication.

What should I do if I'm affected?

Change your password on the affected site and on any other site where you use the same password. Enable 2FA, watch out for phishing emails, and consider using a password manager.
